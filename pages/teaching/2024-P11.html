Introduction : Algorithmique et notations

Dans les algorithmes donnés ci-desous, j'utiliserai le formalisme suivant :

Les variables seront écrites en noir.
La déclaration d'une variable se fera sous la forme suivante : Soit variable : type
L'affectation d'une valeur à une variable se fait à l'aide de l'opérateur = : Soit variable : type = valeur

Les conditions s'écrivent sous la forme Si... alors... Sinon : Si condition Alors instruction(s) Sinon instruction(s) Fin Si

Les boucles Pour s'écrivent sous la forme suivantes : Pour variable de indice début à indice fin avec un pas de pas Faire instruction(s) Fin Pour
Les boucles Tant Que s'écrivent sous la forme suivantes : Tant Que condition Faire instruction(s) Fin Tant Que

Les fonctions et procédures sont écrites en vert, les variables en gris. Chaque fonction/procédure est précédée d'un en-tête précisant les données d'entrée, de sortie, les préconditions éventuelles ainsi que les types manipulés. Voici un exemple d'algorithme affichant les entiers de n1 à n2 dans la console.
Procédure : AfficherEntiersConsole()
Entrée : n1 : entier, n2 : entier
Sortie : void
Précondition : n1 inférieur ou égal à n2
| Pour nombre de n1 à n2 avec un pas de 1 Faire
| | Afficher(nombre)
| Fin Pour
