Introduction : Algorithmique et notations

Voici un exemple d'algorithme afin d'illustrer le formalisme que j'utilise dans mes corrigés.

Fonction : CalculerIMC()
Entrée : taille : réel, poids : réel
Sortie : void
Constantes : TAILLE_MIN : réel = 1.50, TAILLE_MAX : réel = 2.10
Variables : imc : réel
Début
|Si taille < TAILLE_MIN Alors
||Afficher("La taille doit être entre " + TAILLE_MIN + " et " + TAILLE_MAX + ".")
|Sinon
||imc = poids / (taille * taille);
||Afficher("Votre IMC est de " + imc)
| Fin Si
Fin

Pour démarrer, voici un programme basique en C#.

using System;

class HelloWorld
{
public static void Main()
{
Console.WriteLine("Hello World !");
}
}

La première étape est la compilation du notre programme.
Pour ce faire, on utilise le compilateur mono (à installer avec "sudo apt install mono-mcs" sous Linux).
La compilation d'un fichier test.cs s'effectue à l'aide de la commande "mcs test.cs".
S'il n'y a pas d'erreur de compilation, le compilateur génère un fichier exécutable test.exe
Pour lancer l'exécution, on utilise la commande "mono test.exe".
